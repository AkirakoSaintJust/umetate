Fix the operator editor's navigation + ship all 8 FM algorithms

First hands-on pass of fourop-fm surfaced the UI bugs; each is a root-cause fix:

- **Knob 1 changed the algorithm** (and the last row's param was unreachable):
  `ui_slot_param()` counted the `status` widget (which carries `param:
  algorithm`) as page-slot 0. Slot resolution now only counts the five
  param-bearing widget types (`VALUE`/`BAR`/`PARAM_ROW`/`PARAM_COLUMN`/`OP_ROW`),
  so `KNOB1-4` map to the four on-screen params, not the readout.

- **`EDIT`/`FX`/`GLO` were a stack, not siblings.** From `fx` you could not reach
  the operator editor without `HOME` first. A new `switch` action replaces the
  current mode (`ui_switch`: pop to home, then push), so `FX` → `EDIT` goes
  straight to `op`.

- **The operator selector stopped at op 4** (and there was no wrap). `op_next`/
  `op_prev` now wrap around `ui_t->n_op`.

- **Algorithm count was 7, not 8.** The routing table dropped algorithm 3 as
  "algorithm 2's mirror" — that claim was wrong. ymfm's `s_algorithm_ops` is the
  standard TX81Z/DX100/DX21 4-op set {0..7}, and algorithm 3
  (`(O1→O2)+O3 → O4`) is distinct. `_ROUTING` now ships all 8; the `algo`/
  `route`/`route4` clamps and the patch's `algorithm` max move 6 → 7.

- **Param name and value ran together, all one colour.** A param row now draws
  the label in the dim `C_GRAY` and the value + unit right-aligned in the bright
  `C_HI` (the palette's label/value roles), with a gap — the value is the
  high-contrast element, the name the dim reference (WCAG hierarchy).

- The `status` readout only cleared one line of its two-line span (the bottom
  half of the previous page's header lingered); it now clears its full region.
  The envelope drew the release segment twice (r4 was folded into the decay
  stage *and* a fixed flat sustain); it now draws attack/decay1/decay2 →
  sustain → release correctly.

Regression coverage: `ui_test` was stale (predates the `scope` widgets + the
extended `ui_tables`) and not even in the host gate; `accept.h` is rebuilt to the
current schema and `ui_test.c` now asserts slot-0-is-not-status, the operator
wrap, and `EDIT`/`FX`/`EDIT` sibling navigation, and is back in `run_cmake_host.sh`.

Gate green end-to-end; emulator host leg renders the panel (dim labels + bright
values) across home/op/env/fx.
