# Bundled OFL fonts

The editor bundles two fonts as JUCE binary resources:

- `DotGothic16-Regular.ttf`, SIL Open Font License 1.1.
  Source: https://github.com/google/fonts/tree/main/ofl/dotgothic16
- `ZenDots-Regular.ttf`, SIL Open Font License 1.1.
  Source: https://github.com/google/fonts/tree/main/ofl/zendots

The licence texts are `OFL-DotGothic16.txt` and `OFL-ZenDots.txt`. Keep them
with any binary distribution that contains the font data.

The `TYPE P.` wordmark prefix uses Arial Black when the system has it, with a
default bold sans fallback. Digital Desolation Plus is not bundled. The `fm1`
suffix always uses the bundled Zen Dots.
